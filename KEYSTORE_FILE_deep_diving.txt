## What is a Keystore?

--An Android keystore file is a secure file (`.jks` or `.keystore`) that stores your app’s private
signing key, used to digitally sign Android apps so Android and
[Google Play Console](https://play.google.com/console?utm_source=chatgpt.com) can verify the 
app’s identity and allow trusted updates.


--You can create a keystore completely separately, even without any app project using command below:

************************************

 keytool -genkey -v \
-keystore mykey.jks \
-keyalg RSA \
-keysize 2048 \
-validity 10000 \
-alias upload

**************************************

--The keystore is just:
                       --> a container for cryptographic keys
                       --> protected by passwords
                       --> It does not contain your Flutter code.
                       --> Your digital identity/signature


--The app uses the keystore during build time where by Android uses your keystore to create 
a unique digital identity for the app. 

--At this point, Google now knows: “This app officially belongs to the owner of Keystore file A.”

--Later when updating the app, Suppose you change:
          --> UI 
          --> features
          --> bug fixes

so then You rebuild by run command: " flutter build appbundle " so Again, the app is signed using 
the SAME keystore.

--When uploaded, Google checks: " Old app signature == New app signature ?  " so If signatures 
MATCH, Google says: “Yes, this is the real developer.” Then:
         --> update is accepted
         --> users receive update normally
        
--If signatures DO NOT MATCH, Example: first release used Key A and update uses Key B, so for that
Google says: “This is not the same developer.”, Then:
         --> update is rejected
         --> existing users cannot update

Typical error:    "   App signing key certificate mismatch    "


--Why this system exists, Imagine if signatures were not checked. hence
Anyone could:
          --> Download your APK
          --> Modify it
          --> Upload fake updates pretending to be you

so Signing prevents that.
